Drop a few real `.wav` clips here (e.g. a couple from your EGFxSet download,
one per effect you want to showcase) and they'll automatically show up as
one-tap "try an example" buttons in the app — no code changes needed.

The button label is just the filename, so name them descriptively:
`clean.wav`, `distortion.wav`, `chorus.wav`, etc.

This folder ships empty on purpose — the synthetic clips used to test the
picker mechanism during development aren't real guitar audio and don't
belong in a portfolio demo.
